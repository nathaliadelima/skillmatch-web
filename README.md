# 🚀 SkillMatch

Sistema desenvolvido em HTML, CSS e JavaScript puro para analisar a compatibilidade entre candidatos e vagas de emprego.

O projeto foi desenvolvido como atividade avaliativa do módulo de Front-End e tem como objetivo aplicar conceitos de lógica de programação, JavaScript moderno, manipulação do DOM, responsividade, persistência de dados e organização em módulos ES.

---

## 📌 Funcionalidades

- Cadastro do perfil do candidato
- Análise de compatibilidade entre candidato e vagas
- Identificação da vaga mais compatível
- Recomendação personalizada de estudos
- Salvamento automático do perfil utilizando LocalStorage
- Carregamento das vagas através de Fetch API
- Interface responsiva para desktop, tablet e dispositivos móveis

---

## 🖥️ Demonstração

Ao preencher:

- Nome
- Área de atuação
- Habilidades
- Tempo de experiência

o sistema compara automaticamente o perfil com as vagas cadastradas e apresenta:

- Percentual de compatibilidade
- Habilidades encontradas
- Habilidades faltantes
- Classificação da vaga
- Melhor oportunidade
- Recomendações de estudo

## ▶️ Como executar

1. Clone este repositório.

```
git clone <link-do-repositório>
```

2. Abra o projeto no Visual Studio Code.

3. Execute utilizando a extensão **Live Server**.

> O projeto utiliza módulos ES e Fetch API, portanto não deve ser aberto diretamente pelo arquivo HTML.
